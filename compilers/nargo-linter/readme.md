# vmz-linter

> Cvo 框架的高性能静态代码分析工具，守护代码质量的自动化哨兵。

## 📖 简介

`vmz-linter` 是 Cvo 编译工具链中的核心检查组件。它通过对 `nargo-ir` 中间表示进行深度语义分析，能够识别代码中的潜在错误、反模式以及风格问题。它不仅支持传统的脚本检查，还能深入模板和样式块，提供全方位的代码质量保障。

## ✨ 核心特性

- **语义级分析**: 区别于简单的正则匹配，基于编译器的 IR 进行精确的语义推导，减少误报。
- **插件化规则系统**: 提供灵活的 `LintRule` 接口，开发者可以根据项目需求轻松扩展自定义检查规则。
- **全栈检查能力**: 覆盖 Cvo 组件的所有组成部分，包括 `<script>`、`<template>` 和 `<style>`。
- **高性能异步执行**: 利用 Rust 的并发优势，在处理大规模工程时依然保持极速的响应。

## 🏗️ 核心数据结构

- **Diagnostic**: 记录 lint 发现的每一个问题，包含错误代码、详细描述、严重程度（Severity）及源码位置。
- **LintRule**: 异步规则 Trait，定义了规则的唯一标识及针对 IR 的校验逻辑。
- **CvoLinter**: Linter 引擎的主入口，负责集成解析器并调度所有注册规则的执行。

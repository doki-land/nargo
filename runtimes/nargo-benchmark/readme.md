# nargo-bench

> Nargo 框架的性能基准测试工具，量化每一行代码的运行效率。

## 📖 简介

`nargo-bench` 是 Nargo 生态中的性能守护者。它提供了一套自动化、高精度的性能基准测试方案，能够自动识别代码中的性能瓶颈，对比不同算法实现的效率差异，并产出详尽的性能报告，确保 Nargo 框架及其应用始终保持在性能巅峰。

## ✨ 核心特性

- **高精度计时**: 利用原生硬件计数器，提供纳秒级的函数执行耗时统计。
- **自动回归测试**: 集成在 CI/CD 流水线中，自动监测性能劣化风险。
- **多维度分析**: 支持 CPU 耗时、内存分配、冷热启动等多维度的性能度量。
- **火焰图集成**: 能够自动生成函数调用火焰图，直观定位性能重灾区。

## 🏗️ 核心逻辑

- **BenchSuite**: 基准测试套件管理器，负责组织与运行测试用例。
- **MetricsCollector**: 性能指标收集器，统合各种底层性能数据。
- **ReportGenerator**: 负责将测试结果转化为易读的性能趋势报告。
